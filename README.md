# podcasts

Static GitHub Pages site holding private-use podcast feeds, generated by
`Personal/podcasts/build.py` (not in this repo). Each feed is a folder:

- `scotus/feed.xml` — SCOTUS Prep: pre-argument briefs and decision notes
- `reading/feed.xml` — Reading Queue: articles and documents sent to audio

Add a feed URL to Pocket Casts or AntennaPod. Episodes are MP3s rendered with Edge TTS.
